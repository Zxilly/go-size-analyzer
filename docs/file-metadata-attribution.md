# 文件元数据与多证据归属

本轮扩展将原生符号表条目、符号名称等仅有文件偏移的记录纳入物理台账，并保留同一对象的多种归属证据。它建立在现有聚合变量和静态读取分析之上；不包含新的静态指针图、通用控制流分析或 retained size 计算。

## 文件范围与包归属

`wrapper.LoadFileMetadata` 返回两类信息：可按格式验证的文件结构范围，以及与已定义 text/data 符号关联的表记录和名称范围。

- ELF 支持 32/64 位、大小端、符号表、字符串表和扩展节索引；识别 Go 编译器元数据节。
- PE 解析 section 外的 COFF 符号表和字符串表。辅助记录跟随主符号；短名称已包含于表条目，长名称单独计量并包含终止 NUL。
- Mach-O 解析符号表、字符串表及 load command 明确指向的链接结构。`__LINKEDIT` 内未被具体结构引用的空隙仍保留未分类。Go 符号的前导下划线仅在名称匹配时规范化，文件名称范围仍包含它。

结构解析成功只能使字节成为 `recognized`。关联到已有定义包后，对应表条目和名称才成为 `attributed`，来源分别为 `symbol_table` 和 `symbol_name`。起点和 text/data 类型必须一致；排除零大小定义、仅有引用的记录、未定义符号、BSS 和没有文件支撑的目标。名称本身不能创建包归属。

先尝试精确符号名匹配。没有匹配时，仅在候选定义包唯一时允许同址别名回退；多包歧义保留 `recognized`。共享名称、字符串尾部复用及重复表记录通过物理区间并集计量。

所有范围在入库前验证文件边界和整数溢出。原生元数据解析失败时丢弃整批新增声明，并在 `coverage.notes` 记录原因，已有分析结果仍可输出。`--no-symbol` 跳过符号附属记录归包，但保留文件结构识别。

## 多证据与统计口径

`AddrSpace.Get` 保留按起点查找的常数时间入口；`AddrSpace.All` 按确定顺序遍历完整证据。区间按起点、长度、类型、包、来源、角色和边界依据区分，不会用较长证据扩张较短证据。等价证据的多个名称只选择一个确定性代表，避免共享类型名称产生重复记录。

报告使用 `coverage.version = 2`。`--coverage-details` 的每个物理区间新增：

- `definition_owners`：给出该区间定义的包。
- `referrers`：读取或引用该区间的包。
- `evidence`：把包、来源、角色和边界依据绑定在一起的证据列表。

存在定义时，`owners` 只包含定义包；没有定义时才由引用包参与归属。引用证据仍保留，不会因为定义已知而被覆盖。固定宽度读取和复制可以引用已有数据定义；启发式字符串仍遵守原来的重叠过滤规则。

`attributed`、`recognized` 和 `unclassified` 互斥且之和等于输入文件大小。`shared` 按有效 `owners` 集合统计，是 `attributed` 的子集。`by_source` 表示各来源的证据覆盖量，包含有定义时仍保留的引用证据，不能将不同来源相加得到总大小。

包的 `size` 和 section 的 `known_size` 都由同一物理分区计算。父包包含其子包的区间并集，同一字节只计一次；兄弟包仍可能共享字节。`metadata_size` 表示该包直接拥有的符号附属元数据并集，不包含子包，零值省略。文件和符号明细仍是对象视图，可能重叠，不能相加替代包大小。

UI 在包内显示符号元数据，section 仅显示尚未归包的余量；section 外的已归属元数据也从未映射面积中扣除。旧报告没有版本字段时保留旧展示规则。CLI JSON 和 WASM JavaScript 输出使用相同的零值省略语义。

## 独立修复

Mach-O 外部链接产物的 DWARF section 可能有有效文件偏移而没有虚拟内存映射。读取器改按文件偏移读取，并还原被 16 字节字段截断的 DWARF section 名称。回归同时覆盖压缩和未压缩的 DWARF 5 索引字符串、地址及 range 表，以及真实 Go 1.27 CGO/PIE 样本。

当文件含调试段、DWARF 加载或扫描失败且分析继续时，`coverage.notes` 记录具体失败原因；没有调试信息仍报告 unavailable。函数区间逆序或总长度溢出则沿用上游安全检查，返回错误并终止分析。同址别名的多包歧义回退、JSON v2 数值零值与 WASM 输出不一致，也分别有回归测试。

## 验证与复现

物理台账测试覆盖重复证据、部分交叠、定义优先引用、父子包并集、共享名称、符号关闭选项和 section 投影。原生解析器测试覆盖大小端、32/64 位、辅助记录、扩展节索引、截断和溢出。真实编译用例独立读取 ELF symbol、pclntab 和 DWARF 边界，确认三种来源及各自长度同时保留。

```sh
go test -mod=readonly ./...
go test -mod=readonly -race ./internal/entity ./internal/knowninfo ./internal/wrapper ./internal/disasm
go test -mod=readonly ./internal/knowninfo -run 'TestBuildFileCoverage|TestSymbolMetadata|TestCompiledFunctionPreserves' -count=1
go build -mod=readonly -o gsa ./cmd/gsa
./gsa scripts/bins/docker-compose-linux-x86_64 --compact --coverage-details -o report.json
```

WASM 输出一致性测试在 `GOOS=js GOARCH=wasm` 和可用的 `go_js_wasm_exec` 环境运行 `go test -mod=readonly ./internal/entity ./internal/result -run '^Test'`。Windows 上完整 WASM 测试还可能触发已有 fuzz corpus 目录读取的 `O_DIRECTORY is not supported on Windows`；这不影响上述普通测试，但不应据此宣称完整 WASM fuzz 路径通过。

样本守恒和范围检查不能证明所有归属都正确；动态数据、没有定义证据的对象、未解析的元数据及歧义别名仍保留相应限制。

## 保持归属结果的性能优化

随后以功能集成阶段的最终版本为基线，继续减少重复计算与临时分配：

- 台账对重复的包、来源和边界依据使用整数 ID，直接保存起止事件；活动证据计数和包层级并集使用数组，减少字符串哈希、扩容复制与 GC 扫描。
- 包的同步统计改用 `OwnAddressValues`，不再为每个合成范围创建临时地址对象。原指针接口继续提供独立快照；单证据插入、比较和地址排序也减少了分配。
- 原生类型校验先检查各类型的地址包络，能够证明互不交叠时无需存储全部区间。包络交叠时继续精确检查；溢出或跨类型交叠时回退现有归并，保留其错误返回和 disasm 例外。
- DWARF kind 扫描同时保留归属需要的条目，成功后直接使用，避免再次解码整个树。遇到 sibling 属性或非标准树形时回退原 reader，保留完整扫描的错误语义。

本轮性能优化版本完成 40 组完整 JSON 对照，共比较 26,081,151 个节点，零差异：17 个真实样本均比较普通报告和详细区间报告，小 ELF 另外逐项关闭反汇编、符号、DWARF。数值精确比较，regions 及内部证据顺序不作规范化。
